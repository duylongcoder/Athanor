# Phase 1: the MVP run

Dates: 2026-11-11 to 2026-11-12. Spec: `docs/superpowers/specs/2026-11-11-athanor-design.md`.
Plan: `docs/superpowers/plans/2026-11-11-athanor.md`.

## What shipped

- A run-based alchemy puzzle in Unity 6000.6.7f1 for WebGL: 5 depths, a 3x3 bench, 8 starting materials,
  31 discoveries, one ultimate (`worldseed`), 10 catalysts, pair recipes only.
- Art generated by code (`tools/art/`, 119 sprites); rules in plain C# with tests; content in `content.json`.
- Release web build 10.4 MB, 0 console errors in headless Chrome; journal kept across reloads.
- Tests at the end: 65 rule tests (`dotnet test tools/CoreTests`), 69 passing in Unity edit mode.

## Rulings that changed the plan

- Discoveries stay in a 12-slot rack, not the satchel: shuffling results into the deck made an all-knowing
  player win 0 of 100 runs; after the change about 82%.
- A discovery is used up when it reacts; a fizzled one returned to hand (reversed in Phase 2).
- Unspent trials carry to the next depth; making the ultimate wins at any depth.
- Text is world-space TextMeshPro on sprites, not uGUI.
- Reactions on the bench speed up as an Ignite goes on; several discoveries in one Ignite gather faster.

## Left open

- The pixelfx overlay sheets are not exported (`tools/fx/export.sh` has to be run by the owner).
- At window sizes between 640x360 and 1280x720 the game shows at 1x.
